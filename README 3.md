## Publish on GitHub Pages
1. Create a new repository on GitHub, for example `portfolio`.
2. Upload **the contents** of this folder (not the folder itself), so that `index.html` sits at the root of the repo.
3. In the repo, go to **Settings → Pages → Build and deployment**. Set Source to **Deploy from a branch**, Branch to **main** and the folder to **/ (root)**, then click **Save**.
4. After about a minute the site is live at `https://<username>.github.io/portfolio/`.
5. To use your own domain: in **Settings → Pages → Custom domain**, enter the domain and follow GitHub's DNS instructions.

## Things to update
- **Social links:** in `build/build.py`, find `SOCIALS` and replace the placeholder email, WhatsApp number, Instagram and LinkedIn addresses. Then rebuild (see below).
- **Futura PT:** all titles and text are set in Futura PT. It comes from Adobe Fonts (part of Creative Cloud): at fonts.adobe.com create a *web project* with **Futura PT** and **Futura PT Bold**, add your site's address, copy the project ID (the `xxxxxxx` in `use.typekit.net/xxxxxxx.css`), paste it into `ADOBE_FONTS_KIT` at the top of the fonts section in `build/build.py`, and run `python3 build/build.py`. Until then the free look-alike Jost is shown.

## Editing content
The pages are generated by `build/build.py`. To change text or the order of images:
1. Edit `build/build.py`.
2. Run `python3 build/build.py` (requires Python with Pillow: `pip install pillow`).

You can also edit the `.html` files directly. Note that running the build again will overwrite those edits.

Colors and sizes are set in the variables at the top of `assets/css/style.css`.
